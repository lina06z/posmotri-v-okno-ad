# Посмотри в окно

Учебный проект Яндекс Практикума. Задача — оформить готовое веб-приложение с помощью CSS в соответствии с [макетом в Figma](https://www.figma.com/design/ApJjZAA3pBv2tCZM9E2ul2/2-спринт.-Посмотри-в-окно?node-id=0-1), сохранив его функциональность.

## Возможности приложения

- Поиск видео по городу и времени суток.
- Просмотр выбранного видео в основном окне.
- Загрузка дополнительных карточек с видео.
- Отображение прелоадеров и сообщений об ошибках.

## Технологии

- HTML
- CSS (Flexbox, псевдоклассы и псевдоэлементы)
- JavaScript (логика приложения предоставлена в стартовом проекте)
